## Coast Local

- ユーザー自身の過去の画面活動が答えの根拠になり得る場合は、頼まれる前でも `coast-cli-skill` を読み、その検索手順と guardrail に従う。典型的なトリガーは「さっき／昨日／以前」「見た／読んだ／やった」「あのサイト・画面を探して」「作業時間・セッション」「過去の調査・障害を要約／再開」。
- Coast は過去画面を探索する記憶レイヤーであり、現在の canonical state や作業完了の証明ではない。一般知識、現在の Web、repo、ブラウザ、ログ、ネイティブアプリを直接確認できる事柄にはそれらを優先し、Coast の候補は必ず元データと照合する。
- 取得は時間・アプリ・ドメイン・件数を狭く始める。パスワード、認証情報、秘密鍵、金融・医療・人事・法務、他人の私信を含み得る検索は通常の自動利用から除外し、生の秘密値やスクリーンショットを回答へ転載しない。
- 録画はローカルでも、CLI 出力を Claude Code / Codex が読むと選択内容は AI 提供者へ送られ得る。取得・送信範囲を最小化する。録画・除外・保持・削除の設定変更は、検索とは別の副作用として明示依頼なしに行わない。
- `coast` が使えない、記録がない、または shell / skill のない通常の ChatGPT 会話では、利用したふりをせずその境界を明示し、推測で埋めない。
