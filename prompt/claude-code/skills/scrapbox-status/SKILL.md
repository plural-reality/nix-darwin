# scrapbox-status — ステータス絵文字とタイトル規約の単一正本

2026-07-24 ユーザー決定(ask-page 回収)。**状態語彙をここ以外で再定義しない**(他 skill はこのファイルを参照する)。旧規約からの変更点: ⌛️廃止・🚨新設・cc: の正式化。

## 状態語彙(タイトル先頭・カンバン行頭)

| 絵文字 | ラベル | 意味 = ボール保持者 |
|---|---|---|
| ⬜ | 未着手 | 自分(高木)のボール。今すぐ着手できる(自分の実作業中も含む) |
| ⏳ | 進行中 | ボールが自分以外にある(外部の相手、または claude=cc: 付き)。返答/完了待ち |
| ⏹️ | 保留 | 誰のボールでもない。今は着手できない(依存待ち / someday) |
| 🚨 | 人間の判断待ち | **高木の一手で進む**。claude が質問/承認/認証情報などで停止中 |
| ☑️ | 完了 | 終わった。頭から消してよい |

- **🚨 は「今すぐ自分が動かせるもの」の目印**。エージェントがエラーを自律処理中・調査継続中は 🚨 にしない(⏳cc: のまま)。
- **☑️ は控えめに**: 保留作業・未解決ブロック・人間確認が残るなら ⏳/🚨 のまま。
- **⌛️(⌛)は廃止**(⏳へ統合)。新規に書かない。既存タイトルの移行は scb-lint が提案し、都度 scrapbox-rename で行う。
- **✅ はタスク状態に使わない**(完了は ☑️)。リリースノート等の「リリース済み ✅」は別レジスタの表示専用として存続。
- ⚠️(リスク)・❌(却下)は本文注記用。タイトルの状態としては使わない。

## cc: マーカー(実行者軸 — 状態軸と直交)

- claude(coding agent)が自分で回しているタスク: **`⏳cc: {タイトル}`**
- 人間の入力が必要になった: **`🚨{タイトル}`**(cc: は外す=claude はもう回していない)。回答を得て再開したら `⏳cc:` に戻す
- 完了: **`☑️{結論がタイトル単独で分かる断定形}`**(cc: は外す)
- deep-research など数十分かかる作業ほど、着手印 `⏳cc:` を**先に**残す(放置に見えない・二重着手を防ぐ)

## ステータス変更 = 必ず scrapbox-rename(素の write 禁止)

タイトルの絵文字を変える(⬜→⏳cc:→☑️ 等)のは**リネーム**。必ず `scrapbox-rename <project> "<旧>" "<新>"` で行う(ID保持+被リンク張替え込み)。scrapbox-write で新タイトルのページを作って旧を放置しない — これが二重ページとリンク切れの主因だった(2026-07-24 実測: 破損30件・延べ約90ページ)。

- `replaceLinks` が 403 でも `deepLinkPagesFixed` が websocket 経由で補完する。rename 後は旧タイトルの被リンク残存を `cosense-fetch -s "<旧>"` で必ず確認
- **ステータス変更はトピック変更ではない**: prefix だけ更新しタイトル本文の意味を保持する。例外は完了時の `☑️{結論}` 化のみ
- 旧タイトルは既存ページの実バイト列に一致させる必要がある: **必ず API 応答(検索結果の `title` / pages API)からコピー**する。VS16 は不可視なので手打ちは事故る

## VS16 正規形(ツール層が機械的に守る)

`scrapbox-write` / `scrapbox-rename` は入口で `scrapbox-title-normalize.mjs` により自動正規化する:

- ☑️ ⏹️ ⚠️ = VS16(U+FE0F) ちょうど1個(text-default 文字)
- ⬜ ⏳ ⌛ ✅ ❌ 🚨 = VS16 なし(emoji-default 文字)
- タイトル先頭に取り残された裸の VS16 は除去

例外挙動: 与えられた表記**そのまま**のページが実在する場合、scrapbox-write はそのページを正とする(mid-page 編集を別ページへ逸らさない)。

## ToDoカンバンとの関係

- タスク項目の**行頭絵文字とページタイトル先頭の絵文字は一致**させる(ズレたら scrapbox-rename で追従)
- 「LLMがやれること」の todo/wip/done キューは進捗の別軸(セッション単位の外注キュー)。done 列に置くとき: 完了なら ☑️、人間確認待ちなら 🚨
- カンバン自動更新(todo-gap-analysis)はタイトルに触らない。タイトル状態の変更は wip-crawl か対話セッションが scrapbox-rename で行う
