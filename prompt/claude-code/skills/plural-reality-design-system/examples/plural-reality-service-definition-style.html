サービス概要
1.1 サービスの目的

倍速会議は、地方自治体・公共機関の会議プロセスを AI によって構造化・効率化する SaaS プラットフォームです。会議の録音・文字起こし・要約・アクション抽出・議事録生成を自動化し、担当者の会議関連業務を最大 70% 削減します。

1.2 対象ユーザー
  • 地方自治体の政策立案担当部門（企画課・政策調整課等）
  • 議会事務局・委員会事務局
  • 首長・副首長直轄の特命チーム
  • 公共機関・外郭団体
1.3 主要指標（実績）
  • 導入自治体数: 68自治体（2026年6月時点）
  • 会議処理件数: 月間 4,200件
  • 平均議事録作成時間: 3分以内（従来比 -89%）
  • NPS スコア: 72（業界平均 38 を大幅上回る）
1.4 提供形態

クラウド型 SaaS（マルチテナント構成）。オンプレミス・プライベートクラウドへの展開にも対応可能（別途見積）。API による既存システムとの連携を標準サポート。

機能仕様
2.1 コア機能
  • リアルタイム文字起こし — 対面・オンライン会議の音声を 99.2% 精度で日本語テキスト化
  • AI 要約・構造化 — 発言を「報告」「議論」「決定」「宿題」に自動分類
  • 議事録自動生成 — 組織フォーマットに準拠した Word / PDF を即時出力
  • アクション管理 — 担当者・期限を自動抽出し、タスク管理ツールへ連携
2.2 対応環境
  • Web ブラウザ: Chrome 110+, Edge 110+, Safari 16+
  • 会議ツール連携: Zoom, Teams, Google Meet（拡張機能）
  • モバイル: iOS 16+ / Android 12+（専用アプリ）
  • オフライン会議: 専用録音デバイスまたはスマートフォンアプリ
2.3 連携 API
  • REST API v2（JSON over HTTPS）
  • Webhook によるリアルタイム通知
  • SAML 2.0 / OIDC による SSO 対応
  • 庁内文書管理システムとのコネクタ（個別対応）
2.4 非機能要件
  • 稼働率: 99.9% SLA（計画メンテナンス時間を除く）
  • 応答時間: API 95パーセンタイル 200ms 以内
  • データ保存: 国内リージョン（東日本 / 西日本）のみ
  • バックアップ: 日次フルバックアップ、30日間保持

セキュリティ・コンプライアンス
3.1 認証・認可
  • 多要素認証（MFA）必須
  • ロールベースアクセス制御（RBAC）: 管理者 / 編集者 / 閲覧者 / ゲスト
  • セッションタイムアウト: 無操作 30 分で自動ログアウト
  • IP アドレス制限（オプション）
3.2 データ保護
  • 通信暗号化: TLS 1.3
  • 保存暗号化: AES-256
  • 音声・議事録データの学習利用: 不可（契約で明示）
  • データ削除: 退会後 30 日以内に完全消去
3.3 認証・準拠
  • ISO/IEC 27001 認証取得
  • 政府情報システムのためのセキュリティ評価制度（ISMAP）登録申請中
  • 個人情報保護法・行政機関個人情報保護法 準拠
  • 地方公共団体情報システム機構（J-LIS）ガイドライン対応
4.0 導入・サポート体制
4.1 標準導入フロー
  • Step 1 — 要件ヒアリング・環境確認（1〜2週間）
  • Step 2 — アカウント設定・SSO 連携（1週間）
  • Step 3 — 管理者トレーニング（半日）
  • Step 4 — パイロット運用（1ヶ月）
  • Step 5 — 全庁展開・定着支援（継続）
4.2 サポート体制
  • 平日 9:00〜18:00 メール・電話サポート（標準）
  • 24/7 障害対応（エンタープライズプラン）
  • 専任カスタマーサクセス担当者配置（エンタープライズ）
