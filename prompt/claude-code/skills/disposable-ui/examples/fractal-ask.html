決定欄

各設問は選択肢か自由記述のどちらでも回答できます（選択肢に無ければ自然言語で書けば、それが回答になります）。迷ったら「推奨をすべて選択」。押印でローカルサーバが回収し頁は消滅／サーバ死でも「回答をコピー」で貼り戻せます。

回収済
回答はエージェントが回収しました。ターミナルに戻ると作業が続いています。
フラクタル要約: L1本質→L5全文を1本のスライダーで(fractal-reader と同一機構・←/→キーでも移動)。層はページに静的に同梱(閲覧時にLLM呼び出し無し)。
回収は transport 非依存: ①ローカル単発サーバ(POST /submit→ファイル→自死) ②リモート持続(トークンURLの submissions) ③どちらも不可ならクリップボードに copy-as-prompt。
