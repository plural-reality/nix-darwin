# 新聞の文章を書く

新聞らしさは、語尾を切ることより、何があったかを先に伝え、具体的に説明する順序にある。依頼された読者、目的、語り口を優先し、次の順に原稿を整える。

## 1. 記事の用件を先に伝える

- 見出しと冒頭で、誰が何をしたか、何が分かったかを伝える。背景や経緯はその後に置く。
- 誰が、いつ、どこで、何を、なぜ、どのように、という要素を記事全体にそろえる。一文へ全てを詰め込まない。
- 主体や出来事が分かる見出しにする。抽象的な標語だけで記事の内容を代用しない。
- 解説や人物記事など、目的に応じて構成を変える。全ての記事を同じ型に押し込めない。

## 2. 本文を自然な日本語にする

- 記事本文は簡潔な常体を基本にする。「である」を増やすのでなく、「聞いた」「検討した」「分かっていない」など、内容に合う述語を使う。
- 見出しは短くできるが、本文では体言止めや倒置を連ねない。省略で意味や文のつながりが見えなくなったら、述語を戻す。
- 名詞を重ねた表現を、誰かの行動や具体的な物へ戻す。専門語が必要なら、その場で読者に分かる説明を添える。
- 一文に一つの中心を置く。事実、理由、評価、問いが重なる文は分ける。固定の字数で機械的に切らず、文の長短で読みやすさを整える。
- 不要な修飾や重複は削る。声に出して読み、主語と述語の距離、接続、息継ぎしにくい箇所を確かめる。

| 圧縮しすぎた表現 | 意味を保った書き方 |
| --- | --- |
| 聞いた後の経過を返す | 意見を聞いた後、経過を知らせる |
| 継続に必要な条件を読む | 続けていくうえでの課題も見えてくる |
| 調査・秘書業務を扱う | 調査や秘書の仕事にAIを使う方法を伝えている |

言い換えは前後の文脈を確かめて行う。最後の例も、実際に方法を伝える活動をしていると確認できる場合に限る。

## 3. 発行者の声と記事本文を使い分ける

発行の挨拶や署名入りの文章では、本人が書いた原稿を優先する。本人の敬体、言葉の選び方、読者との距離を残し、記事本文に合わせて一律に常体へ変えない。参考にできる手書き原稿や過去文面があれば、本人の文章とAIによる要約を区別して読む。本人の文章が見つからない場合は、語り口を再現できたと主張しない。

## 4. 文章を滑らかにしても、根拠の範囲を変えない

- 取材で確認した事実、話者の意見、編集者の解釈、次に調べたい問いを区別する。提案や検討を実施済みの活動に変えない。
- 過去の答弁には時点を残す。現在の状況が不明なら、対応がなかったと断定せず、何を確かめる必要があるかを書く。
- 引用は確認できる発言だけを使う。表情、場の雰囲気、話者の気持ちや会話を創作して記事らしさを足さない。
- 数字には対象、期間、単位、必要な分母を添える。設問別の回答件数、延べ票数、参加人数を取り違えない。少人数の結果を地域全体の意向に広げない。
- 写真や図のキャプションも本文と同じ基準で確認する。別案件の画像やデータを混ぜず、実写・実画面と再構成した図を読者が取り違えないようにする。

## 5. 紙面で読み直す

見出しとリードだけで用件が伝わるか、本文の因果関係がつながるか、出典と未確認事項が残っているかを点検する。字数が収まらない場合は重複や周辺説明から整理し、必要な留保を削って断定を強めない。組版後に改めて読み、改行や段の切れ目で意味が途切れていないかを確かめる。
