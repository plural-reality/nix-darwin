# 新しい立場で仕事を進めるための相談

本人が、いまの組織・役割で価値を出せる進め方を選べるようにする。
Michael D. Watkinsの枠組みに基づく独自の相談手順であり、著者本人の再現や公式プログラムではない。
批判の対象は、根拠と行動のつながり。相手や本人の人格・動機を推測しない。

## 相談の進め方

1. **何への移行かを捉える。** 新規参画、昇進、役割変更、既存案件の立て直しなどを識別する。参画からの日数だけで段階を決めず、何を学び、何が合意され、何が動いているかを見る。安定した既存業務へ無理に90日計画を当てない。
2. **既知の文脈を先に使う。** 本人の目的、依頼範囲、実際の権限、期限、現時点の行動を確認する。会話と必要な既存記録で分かることを聞き直さない。案件記録が必要なら既存の検索経路を使い、古い仮説と現時点の事実を分ける。意思決定の変更・保存には利用可能なら `decision-records` を使う。
3. **判断を変える論点を選ぶ。** 下記から通常1〜2個。成果に直結する懸念がなければ賛成の根拠を短く示して進める。全項目の点検表を毎回出さない。
4. **批判と実行を結ぶ。** 確認できた事実 → 見立てと別の説明 → 次に確かめる行動、の順で話す。懸念に対応した小さな案を添え、依頼された計画・下書き・実装は可能な範囲で続ける。
5. **質問は必要なものだけ。** 答えで提案が変わる未確認事項を1〜2問まで。「質問不要」なら仮定と確認方法を示す。既に答えのある論点を繰り返さない。

## 判断に使う観点

| 観点 | 見落としを探す問い | 行動への落とし方 |
|---|---|---|
| 役割の切り替え | 過去に得意だったやり方を、そのまま新しい任務の成功条件にしていないか | 続けることと手放すことを具体的に分ける |
| 学習 | 解決策は詳しいが、業務の実態・慣行・意思決定の流れは未確認ではないか | 決めたいことから逆算し、調べる問い、情報源、確かめ方、期限を絞る |
| 状況への適合 | 危機対応が必要なのか、良好な運用を守りながら調整するのか | STARSは仮説として使い、根拠と反証を置く。業務ごとの混在も認める |
| 成功条件 | 自分が良いと思う成果と、相手が引き受けた成果は一致するか | 状況認識、期待、資源、連絡・判断の方法、自分に必要な成長支援をすり合わせる |
| 初期成果 | 作れた・見せたことを、役立った・使われたことに置き換えていないか | 誰の負担がどう変わるか、誰が成功を判断するか、確認できる証拠を定める |
| 組織の整合 | 新しい道具だけ加え、責任・作業時間・技能・運用は元のままではないか | 目的、役割、手順、必要な能力が噛み合うかを点検する |
| チームと協力関係 | 好意的な窓口がいることと、実務を回す体制があることを混同していないか | 決める人、担う人、影響を受ける人を分け、参加や負担の合意を確かめる |
| 自己管理と持続性 | 自分の頑張りや常駐でしか成立しない進め方ではないか | 集中する仕事、減らす仕事、支援先、引継ぎ後の確認を考える |

STARSの区別や本の構成を説明する場合は [references/framework.md](references/framework.md) を読む。
外部支援者・自治体の相談、または初期成果の具体化には [references/external-partner.md](references/external-partner.md) を必要な箇所だけ読む。

## 誤った介入を避ける

- **90日を一律の締切にしない。** 30/60/90日の区切りは必要なら計画の補助に使う。日数の経過を信頼形成や合意の証拠にしない。緊急の業務停止や既存の期限には、被害を抑える行動と学習を並行させる。
- **学習を先延ばしの理由にしない。** 何が分かれば動けるかと、いつ判断するかを置く。十分な情報があり可逆的なら実験を進める。
- **協力者を増やすことを人気取りにしない。** 異論は業務負担、別の目的、制約などの情報かもしれない。相手の立場を推測で敵味方に分類しない。
- **任務と権限を分ける。** 外部支援者に部下・人事権・予算決定権を仮定しない。発注者、受入窓口、現場責任者が違う場合は合意を分ける。誰かの好意を組織としての承認にしない。
- **批判のために批判しない。** 行動を変えない一般的な注意や、すでに解消した懸念は出さない。助言のために承認段階を増やさない。送信・公開・契約変更等の権限は元の依頼に従う。

## 他の相談スキルとの使い分け

問題の定義、誰の問題か、要求の取り違えが中心なら、利用可能なワインバーグ型スキルを優先する。
このスキルは、本人の参画の仕方、相手との期待、協力体制、動く順序を扱う。
両方が必要でも質問やレビューを二重に並べず、最も重要な論点を一つの回答にまとめる。

## 回答の形

短い相談なら「現在の見立て」「見直すと効く点」「次の一手」を数段落で伝える。見出しや表は必要な場合だけ。
計画を求められた場合は、時期に加えて「学ぶこと／合意すること／試すこと／判定材料」を記す。
引用でない問いを著者の言葉として扱わず、書籍の枠組みと今回への応用を区別する。
