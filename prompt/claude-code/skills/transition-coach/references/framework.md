## 学習は三つに分けて考える

Genesisの公開説明は、業務・技術に関する学習、文化に関する学習、影響力や意思決定に関する学習を区別する。
スキルでは「業務の課題は把握したが、なぜ今の運用なのか、誰が変更を引き受けられるかが分からない」といった偏りを探す。
情報収集量を成果にせず、次の意思決定に必要な問いを一つ定める。
出典: [Genesis Transition Roadmap](https://news.genesisadvisers.com/the-first-90-days-transition-roadmap)。

## STARSは組織へのラベルではなく、介入を比較する仮説

| 状況 | 区別する意味 | 独自の確認例 |
|---|---|---|
| Startup | 新しい活動の成立に必要な能力を用意する | まだ存在しないのは道具か、役割か、運用か |
| Turnaround | 深刻な不調からの回復 | 放置による損失と、動く権限が具体的にあるか |
| Accelerated growth | 拡大に体制を追いつかせる | 需要増と単なる作業増を区別できるか |
| Realignment | 問題を抱える既存の活動を調整する | 何がずれており、当事者も同じ証拠を見ているか |
| Sustaining success | 良好な状態を維持する | 新しく変えることで壊すものはないか |

同じ組織でも領域ごとに混在しうる。分類への異論は診断の材料。
「反対されたからRealignment」「行政だから抵抗が強い」は証拠にならない。
出典: [Watkinsほか、IMDの移行期解説](https://imd.org/research-knowledge/organizational-behavior/articles/hit-the-ground-running-transitioning-to-new-leadership-roles)、[Watkins、七つの役割転換](https://www.imd.org/research-knowledge/articles/moving-up-to-business-leadership/?segment=2)。

## 成功条件を交渉する五つの会話

著者の公開インタビューでは、状況認識、期待、資源、働き方・連絡方法、成長についての対話を扱う。
スキルでは次を独自の問いとして使う。

- 状況: 自分と依頼者で「何のために入るか」が同じか。
- 期待: 何が変われば成果か。いつ、誰が判断するか。
- 資源: 予算だけでなく、担当者の時間や協力を使えるか。
- 働き方: 相談・決裁・報告の経路と頻度が合っているか。
- 成長支援: この役割を果たすために、自分は何を学び、誰に支援を求めるか。

外部支援への翻訳では「上司」を機械的に「窓口」に置換しない。権限と責任を実際の関係へ対応させる。
出典: [Genesis掲載のWatkinsインタビュー](https://genesisadvisers.com/5-conversations-you-need-to-have-with-your-boss/)。

## 成果の選び方と動く速さ

初期成果は、関係者から重要と見なされ、使える資源と期間で実現できるものを選ぶ、というのがGenesisの説明。
本スキルでは、納品そのものに加えて、利用、相手の負担、再現性のどれを確認すべきかを案件ごとに選ぶ。
すべてを「小さく遅く」にする必要はない。危機対応と、良好な運用の調整では速さが異なる。
出典: [Genesis Transition Roadmap](https://news.genesisadvisers.com/the-first-90-days-transition-roadmap)、[Watkins、課題を解く人から優先課題を定める人へ](https://www.imd.org/research-knowledge/organizational-design/articles/from-problem-solver-to-agenda-setter/)。

## 適用限界

- 管理職向けの考えを、権限のないコンサルや自治体協働に使う部分は応用であり、そのままの処方ではない。
- 組織の事情や公共的な妥当性を「支持を集める技術」で置き換えない。懸念に正当な根拠があれば提案自体を変える。
- 90日、損益分岐点、プログラムの効果を、本人の成果期限や成功確率に換算しない。一般的な効果数値は診断に不要。
- コッターの変革モデルやADKARは別の枠組み。この本の章やWatkinsの主張として混ぜない。
- Genesisの2024年の8項目ロードマップは関連する実務整理。本の10章構成と同一視しない。
